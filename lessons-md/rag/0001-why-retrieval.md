## 开场（页首框｜先别急着学，聊两句）

你把公司的年假制度问模型："请三天年假要走什么流程？"

它答得头头是道——**可那套流程是你上个月才改的，它给的是老版本。**

它怎么知道的？——**它不知道。它在"接得像"。**

**学完这课，你能**说清：模型为什么会"不知道"、RAG 到底做了什么、以及它**一个字都没改模型**是怎么回事。

【选读框｜记住一条主线，后面就不会晕】

**RAG ＝ 让模型考一场开卷考试：回答之前，先从你的资料里查出相关的几段，塞进提示词，让它照着答。**

它**不改模型、不训练模型**——书翻好了递给它，考生还是那个考生。

## 1. 模型为什么会"不知道"？三个短板，但都不是因为它笨

接着开头那句年假流程往下想。它答错，来路有三种。

这三种各有各的脸，挨个认清它们，以后看到模型答错，你能先判断它栽在哪一种上。

**第一种：它没见过你的文档。**训练它用的是公开语料，你的制度汇编、合同、会议纪要，一个字都不在里面。

你问"入职三年，我有几天年假"。答案就在年假制度那份文档里——公司共享盘上的一个 PDF，还是旧版 Word 格式。对模型来说，这份文档压根不存在。

它照样会给你一个数：五天、十天，编的。**数字越具体，越像真的。**你照着去请假，才发现跟制度里写的对不上——错的不是你，是那个凭空来的数。**这是最常见的原因。**

**第二种：它有知识截止（knowledge cutoff）。**训练完成之后才发生的事，它不知道。

上个月监管部门发了新口径，消息还在新闻里，你拿着新规去问它，它给你的却是旧口径。不是它装傻，是它的知识停在训练完成那一刻，那条新闻发生在这条线的右边。

**这种翻车的答案通常是旧的，不是编的**——答得越流畅，你越不会起疑，错的口径就一路带到你的结论里。

**第三种：它学的是"接下一个字"，不是"查事实"。**（[LLM 底层 · 第 0 课](../../lessons/llm/0000-how-models-learn.html)）所以它**不知道自己不知道**。

你问一条它真没见过的规定，它不会说"我不知道"，而是把答案编下去："根据《考勤管理办法》第 8 条……"——条文号、措辞、语气都像模像样，唯独那份《考勤管理办法》第 8 条不存在。

你拿去跟法务对质，才发现出处是编的。这种编造有个通用名字，叫**幻觉（hallucination）**。

开头那套"老版本"就是第三种来路：不是它存着你的旧档案，是旧流程长得像标准答案，它顺着往下接，就接到了那里。

这个三分法是压缩过的，得说清是谁的分法：Pinecone 那篇指南把基础模型的局限列成五类——知识截止、领域知识浅、拿不到私有数据、答不出出处、概率性生成。这里把它们并成三张最常见的脸。剩下两类（答不出出处、领域浅），后面课里还会遇到。

三条短板都不是"模型不行"，是**信息不在它手边**。所以解法不是换更大的模型，而是**把信息递过去**：没见过的文档，放进资料库让它现查；没见过的新规，把那篇报道也放进去。资料在手边了，它就没必要编。

## 2. RAG 就是"开卷考试"：先翻书，再回答

把主线那句话拆开，就是三件事：

```
你的问题
   │
   ├─① 先去你的资料里查：哪几段跟这个问题有关？
   │
   ├─② 把查到的那几段，跟问题一起发给模型
   │
   └─③ 模型照着资料回答
```

**提示词（prompt）**就是你发给模型的那段话。RAG 做的事，说到底就是往这段话里加料。

这一步叫 **RAG（检索增强生成，Retrieval-Augmented Generation）**。名字正好拆成那三件事：**检索**是"翻书"，**生成**是"回答"，**增强**说的是它只在回答之前多拿了几段资料。

这不是课堂玩具：公司里那些"知识库问答"助手，背后大体走的就是这条路。

为什么加了料就管用？因为模型每接一个字，提示词里的全部内容都摆在它眼前。那几段资料不是让它背下来的，是摊在桌上的。它怎么"看"桌上的东西，是 [LLM 底层 · 第 1 课](../../lessons/llm/0001-from-token-to-next-token.html) 的事。

还有两件事，都是后面误会的源头。第一，**那几段资料只在当次回答时在场**：随这一次请求发过去，答完就没了，下一次提问要重新查、重新发——它不是把资料装进了模型。

第二，**RAG 查的是你放进资料库的文档，不是互联网**，跟"联网搜索"是两回事。

也别指望它替你把关资料的质量：资料库里放的是什么、干不干净，答案就跟着是什么。建库怎么建得干净，是「建库」那课的手艺。

比喻的对应就三句：考场＝你的一次提问，书＝你的资料库，翻到的那几页＝塞进提示词的那几段。

哪里不稳？**开卷考试里书总归是有的；RAG 里你的资料可能根本没这段**——翻了也白翻，模型手上还是只有一句问题，该怎么编它还怎么编。

而且书得自己准备：把公司文档整理成能翻的样子，也是后面几课的事。资料缺了段落这种新翻车，[第 9 课](../../lessons/rag/0009-two-failure-modes.html)摆开讲。

**模型本身一个字没变。**它的[参数（权重）](../../reference/glossary.html#weights)，也就是训练时定下来的那套数，从头到尾没被动过。也没有重新训练。

变的只有你发过去的那段话，多了几段资料。

RAG 这个名字的出处论文把这点说得很直白：**换掉那份资料索引，就能更新模型的知识，不用重新训练**。落到你工作里就是：制度改了，把资料库里的那份文档换成新的，下一次提问答案跟着变，不用求着谁把模型再训练一遍。

【图】../../assets/closed-vs-open-book.svg（图片文件不动）

替代文字（alt）：闭卷与开卷两条路对比。上一条闭卷：你问「请三天年假要走什么流程」，模型手上只有那一句问题，于是编一套听着合理的流程。下一条开卷（RAG）：同一句问题，模型手上变成「问题＋查到的两段制度」，照着资料回答。两条路用的是同一个模型。

图注：**闭卷和开卷的差别，全在中间那个盒子。**同样一句问题，模型手上多出查到的那两段，答案就从"编"变成"照着答"。

那为什么不干脆换个更大的模型，或者拿训练把制度塞进它脑子里？

那些是另外的路，价钱各不相同。[第 3 课](../../lessons/rag/0003-when-not-to-use-rag.html)把几条路摆在一起对表。

## 3. 先分清两种「嵌入」，不然后面全混

上面第①步"查哪几段有关"，靠的是**把文字变成数字再比**。这个动作叫**嵌入（embedding）**——但你已经在别的课里见过这个词，而且是**另一个东西**：

|  | 词嵌入 | 文本嵌入 |
|---|---|---|
| 压什么 | **一个 token** → 一根向量 | **一整段文字** → 一根向量 |
| 谁算的 | 语言模型的**第一层**（查表） | **另一个小模型**，专门干这个 |
| 拿来干嘛 | **喂给模型**当输入 | **只用来排序**，挑出该给哪几段 |
| 在哪讲的 | [LLM 底层 · 第 1 课](../../lessons/llm/0001-from-token-to-next-token.html) | 这一课 |

（两条都叫 embedding，很容易混。术语表里有 [词嵌入](../../reference/glossary.html#vector) 和 [文本嵌入](../../reference/glossary.html#text-embedding) 两条，分开写的。）

一条 RAG 链上其实跑着**两个模型**——一个只管把文字变成向量、给段落排序，一个只管答题。它们各干各的，互不相干。

## 4. 动手跑一遍

脚本在工作区：`exercises/rag/0001-why-retrieval.py`。它**不调任何模型**，只演一件事——**不检索 vs 检索之后，模型手上有什么**。

```
python exercises/rag/0001-why-retrieval.py
```

Windows 终端若中文乱码，先执行 `chcp 65001`。下面是输出摘录（跑了就有完整的）。

```json
[3] 不检索时，模型手上有什么
      ——只有那一句问题。资料一个字都没有。
      ——它学的是「接得像」（见 LLM 底层第 0 课），于是会编一套听起来合理的流程。
      ——注意：它不会说「我不知道」。它不知道自己不知道。

[4] 检索：把每段压成一根向量，跟问题比相似度（点积）
      相似度 = 2   段 2．请假三天以内（含三天），向直属主管口头报备即可，事后补一条消息。
      相似度 = 1   段 3．请假三天以上，需在系统里提交申请单，附上证明材料，主管审批后生效。
      相似度 = 1   段 4．报销流程：每月 25 日前提交发票，财务在次月 15 日统一打款。
      相似度 = 0   段 1．年假天数：入职满一年者每年 5 天，满三年者 10 天，满五年者 15 天。
      相似度 = 0   段 5．加班调休：加班满 4 小时可调休半天，调休需当月用完，过期作废。

[5] 检索之后，模型手上有什么
      【资料 1】（原第 2 段）请假三天以内（含三天），向直属主管口头报备即可…
      【资料 2】（原第 3 段）请假三天以上，需在系统里提交申请单，附上证明材料…
      【问题】请三天假要走什么流程？
```

**先看懂两件事**：

- **前后对比是重点。**同一句问题，模型手上从"光秃秃一句"变成"问题 + 两段资料"。**RAG 干的就是这一件事。**
- **"三天以内"和"三天以上"两段都拿到了**——因为问题正好卡在分界线上。只取 1 段，模型看到的就只有半套规则。**取几段，是 RAG 里第一个要调的数。**取少了规则不全，取多了无关的段落挤进来添乱，没有万能答案。

**另外两件顺带的事**：

- **比相似度用的就是 LLM 底层第 1 课那个「点积」**。同一个动作用在两处——注意力里比"像不像"，这里比"相不相关"。你在 LLM 底层课里学的数学，到这里原样能用。
- 脚本里是按"共有的二字组合"来比的，也就是**按词匹配**——这种叫**稀疏检索**。真的 RAG 常常还会同时用**按语义匹配**（把整段压成向量、比远近），叫**稠密检索**。**两种各有各的失手**：换个说法，稀疏就漏；撞上同名不同物，稠密就瞎。所以很多系统**两个一起用**。（[术语表 · 稀疏 / 稠密检索](../../reference/glossary.html#sparse-dense)）

脚本里的段落是按相似度挑的，真实系统挑段落的花样更多——从第 2 课起逐个拆。

到这里，"先查资料再回答"这条路走通了一遍：三个短板说明了为什么必须递资料，开卷考试说明了怎么递，脚本让你亲眼看见递过去前后、模型手上差了什么。

你在 API 里发的那段提示词，形状就是【资料】＋【问题】这样拼起来的。还剩一个问题——**这一整条链，从文档到答案，到底长什么样？**

## 5. 检查一下你懂了没

**Q1　不给模型任何资料，它答不出你的内部流程时，通常会怎么做？**

- 反过来问你要补充的材料
- 明确地告诉你它并不知道
- 干脆拒绝回答这道问题
- ✅ 编一套听起来合理的话给你

答对时：对。它学的是「接得像」，不知道自己不知道，所以不会主动说不知道。
答错时：它不会拒绝、也不会反问——它只会按「接得像」编，编得还很顺。

**Q2　RAG 到底改了模型的什么？**

- ✅ 模型什么都没改，只改了提示词
- 重新训练了一遍，让它记住
- 把资料写进模型的参数里面
- 换了一个更大的模型来回答

答对时：对。RAG 不碰模型，它只往提示词里多塞几段资料。
答错时：RAG 不训练、不改参数、也不换模型——它只改发过去的那段话。

**Q3　「它不知道自己不知道」，为什么是关键？**

- 它没联网，查不到最新的消息
- ✅ 它不会说不知道，只会编答案
- 它回答的速度比搜索引擎慢
- 它只能处理文字，不能看图片

答对时：对。所以「答得顺」不能当「答得对」，得把资料递到它手上。
答错时：联网、速度、图片都不是重点——重点是它没有「我不会」这个反应。

**Q4　你问模型"上个月刚发布的新规怎么算"，它答错最可能因为什么？**

- 新规里的数字它算不过来
- 它只回答跟公司有关的问题
- ✅ 它训练完之后新规才发布
- 它的机器配置跑不动这类问题

答对时：对。这是知识截止：训练之后才发生的事，它只能拿旧口径答你。
答错时：跟算力、题材都无关——它的知识停在训练完成那一刻。

**Q5　拿公司内网的报销制度去问模型，答错了，第一嫌疑是什么？**

- ✅ 这份制度不在它训练过的语料里
- 这份制度是它训练完成之后才改的
- 它分不清"上限"和"下限"两个词
- 这个问题的句子写得太长了

答对时：对。内网文档对它来说压根不存在——没见过，是答错的头号原因。
答错时：先问一句：它见过这份文档吗？内网的文档，从头到尾就没进过它的训练。

**Q6　下面哪件事，用的是「文本嵌入」？**

- ✅ 把一整段文字变成向量，好跟别的段落比远近
- 把一个 token 变成向量，喂给语言模型当输入
- 把答案里的错字一个个挑出来改掉
- 把两段文字拼成一段更长的文字

答对时：对。文本嵌入压的是一整段文字，只用来排序、挑段落。
答错时：分辨看两点：压的是一整段还是一个 token，算它的是另一个小模型还是语言模型第一层。
