# lessons-md/ —— 课件文字稿（markdown 镜像）

这里是 [`lessons/`](../lessons/) 的**逐文件 markdown 文字稿**，目录结构与 `lessons/` 一致：

| 课件 | 文字稿 |
|---|---|
| `lessons/llm/*.html`（基础＋进阶＋附录） | `lessons-md/llm/*.md` |
| `lessons/agent/*.html` | `lessons-md/agent/*.md` |
| `lessons/rag/*.html` | `lessons-md/rag/*.md` |
| `lessons/index.html`（目录页） | `lessons-md/index.md` |

**两个用途**：

1. **直改底稿**：直接在上面改文字，改完交回，由主代理逐段映射回 HTML 并跑核验（首发于 `agent/0003` 的 F5 流程，见 `internal/drafts/agent-0003-f5-markdown.md`）。
2. **文字版**：课件的可读文字版，结构干净（标题＋正文＋表格＋列表），后续可直接转 PPT。

## 怎么改（约定）

改动时**不用讲究格式，只管改文字**；下列标记是给回写用的：

- **✅** 标的是小测正确选项（回写为 `data-correct`）。选项可以改写、可以挪位置，**标记别删**；每题恰好一个 ✅。
- **答对时 / 答错时** 两行是小测反馈（回写为 `data-ok` / `data-no`），可直接改。
- **【图】/【视频】** 处媒体文件不动（路径照旧），图注与「替代文字（alt）」可改。
- **【选读框｜xxx】**＝带标签的注释框（回写为 `.note`）；**【提示框】**＝不带标签的注释框；**【折叠框｜xxx】**＝可折叠的公式/细节块（回写为 `<details>`）；**【goal 框】/【goal 框｜xxx】**＝课文中间的 goal 样式框（白底重点框／课程地图框，回写为 `.goal`）。
- **【三柱框】**＝三栏卡片（回写为 `.pillars`）；**【页内图｜流程】/【页内图｜总图】/【共用框】**＝HTML 画的示意图，**回写时按原结构还原**，下面的文字可改。
- **小节可以增删合并**，节号乱了没关系——回写时会重排，并同步改正文里「第 N 节」的引用。
- **【meta】/【别名（data-alias）】行与页首引言**一般不用动；**页尾互链和一手资料**一般也不用动，链接地址要改也可以直接改。
- 不在 md 里的东西（页面样式、小节锚点 id、页脚元素）回写时由 HTML 原件补齐，不用管。

## 维护

- 本目录由 `tools/html2md.py` 从 `lessons/` **生成**：`python tools/html2md.py --check`（转换＋一致性校验：题数/✅数/图数/标记数/死链）。
- ⚠ **重新生成会覆盖你未交回的修改**——改了一半的稿子先交回或另存，再重跑生成。
- 课件（`lessons/`）与文字稿（`lessons-md/`）目前不自动双向同步：回写由主代理逐段映射（保证节号、锚点、互链、核验全过）。
