- **「层 vs 轮」网格图与 Q11 一起撤掉**（2026-10-01，学习者提出）。基础课第 2 节直接用正文钉死「请求 / 一轮 / 层」三个概念，进阶版 Q11 删除、`layer-vs-round.svg` 删图。**上一条决策（2026-09-30）的根因已过期**——它说"「层」在第 1 课用竖着叠的图、「轮」在第 2 课用竖着往下的图，长得像、意思完全相反"，但**第 1 课后来改成 `llm-pipeline` 流程图，不再是竖着叠的 Block 图**，"两张图长得像"这个前提不存在了。
  - **更根本的一条**：那个"横着是层、竖着是轮"的坐标框架**在任何一手资料里都不存在**。`RESOURCES.md` 里的原话用的是 layer / forward pass / decoding step / position（`0002` 的来源 Redis、ClickHouse，`0001` 的来源 Vaswani §3.2.3、Stanford CS224n），**没有一处把层与轮说成两个垂直方向**。按 1.1「不得凭模型记忆，知识只能来自 RESOURCES.md 列出的来源」，这个框架本来就站不住 —— **它教的是自造的比喻，不是机制**。
  - **教训**：当初那次卡住是**理解偏差**，不是材料模糊。**给理解偏差配一张 1051 字的图 ＋ 一个自造坐标，是用重装备掩盖轻问题。**判据补一条：**图和类比在落地前先回 `RESOURCES.md` 查一次出处** —— 查不到出处的框架性比喻，一律不进课件。
  - 连带清理：术语表 `#layer` / `#round` 两条里的"竖着叠／横着走／两个垂直的轴／网格图里一列一层"全部改写；`0002` 基础课与进阶版里指向 `#q11-axes` 的 3 处链接改掉或删除。
  - `(n+m)×L` 那个算式随 Q11 一起删：Q3「算力受限/带宽受限」已覆盖单轮算术强度，本课的成本结论不依赖总量式。
- **基础课「架构图 vs 流程图」判为重复**（学习者提出 2026-09-30）。核对结论：重叠约 85%，架构图唯一独有的只有左边那列形状标记。**"简化架构图"解决不了**——decoder-only 的架构图本质就是这条链，简化完只是流程图少几个字，还得养第二张图、还得让读者在两张图之间建映射；**"搬进进阶版"会变成三份**（进阶版已有总链 + Q2/Q3 已讲透）。→ 删掉，**归 `reference/`**（见 1.4 的三去处表）。顺带**基础课删掉"LM Head"**：术语表原本就没有它、全课再无第二次出现，留个没有回报的词是纯负担。
- **`llm-pipeline` 上有一条底色带＝「模型本体」，边界钉死在 `查嵌入表 → 打分结束`（2026-09-30，学习者提出"把属于模型结构的用大框框起来"）**。
  - **学习者原本把上边界画在「分词」之前——差了一步**。分词、查词表确实不算模型，但**查嵌入表算**：那行向量是**训练学出来的参数**，不是固定查表值，它就是模型的第一层。**所以上边界在「查嵌入表」这一步，不在它前面。**
  - **下边界学习者没提，但同样存在**：**softmax 和采样不是模型干的**——模型只交出那张分表就下班（= `0001-deep` Q9 的原话）。带子画到 `原始分(logits)` 为止。
  - **带子的画法**：只留底色、**不加边框**（边框会和两侧的框贴成一条），左右各留 20px、上下留 15～20px，**让进出箭头跨过带子边缘**——箭头穿过边界本身就读作"进入/交出"，比任何边框都清楚。
  - **这条同时把两个进阶版答案画进了基础课图里**（Q2 的模型边界、Q9 的分表之后不归模型管），是意外收益。
- **`base.css` 两个组件**：`details.formula`（白话讲透、公式按需展开，打印时全展开）· `.chain`（见 5.2）。

- **`llm/0001` 嵌一段演示动画，位置是 `note` 之后、§1 之前**（2026-10-06 学习者定）。素材是学习者自己生成的 `assets/llm-pipeline-answer.mp4`（1280×720 / 103 秒 / 7.7MB），另配一张从 gif 抽的 poster。
  - **位置判据：那段动画的底部字幕就是整节课的压缩版**（① 切法不等于「词」· ④ Block 四步 · ⑥ Softmax 加起来 = 100% · 结尾"一次问答 = 流水线走 5 遍"）。放最前面是「先看一遍短的，再读详细的」；放到 §4 或后面，就是读者读完 §1–§3 再看一遍压缩版 —— 正是 1.5 第 1 问点名的"注意力被占了两遍"。**放 `note` 之后而不是 `goal` 之后**：`goal` 的规矩是"别一上来就讲知识"，而 `note` 已经把「计算机只认数字、整条路只有向量」立住，读者看动画时知道该盯什么。
  - **用 mp4 不用同内容的 gif，两条实测理由**：① 体积 7.7MB vs 13.9MB；② **正文栏只有 44rem（704px），gif 是「854 渲染完再缩到 704」＝二次降采样、字幕发虚，mp4 是「1280 缩到 704」**。同族于 1.7 记的「`llm-pipeline` 画布撑宽后等效字号被压小 20%」。
  - ⚠ **静态图九站、动画七格，不是同一套编号** —— 动画把「只取最后 1 串」并进了前后一步、最后那个 token 没单列成格子。**这句差必须在图注里写明**，否则读者拿 §2 的「第 ③ 步」「第 ④ 站」去动画里找会找不着（1.5 第 2 问：新增东西会让旧说法对不上时，同一次改掉）。
  - **poster 取第 1050 帧**（七站齐全、④ Block 高亮且内部四步可见、token 行已长到 7 个、回答框「我是 AI」）。**中间那几帧带放大浮层、会把整条链盖住**，不适合当静止封面。
  - **两处已知限制、这次没做**：滚出视口就暂停（IntersectionObserver，103 秒循环在课底还在播）· 打印时换成 poster（§2 那张静态 SVG 已覆盖打印读者）。
  - **`assets/llm-pipeline-anim.gif` 是旧版（学习者不满意，准备删），`llm-pipeline-answer.gif` 是同内容的 gif 版（没用上）—— 两个都未被任何页面引用。**
  - **`base.css` 的 `figure.figure` 原来只写了 `img`**，视频不生效 → 补上 `video` 同规则。`muted` + `playsinline` 两条不能省：iOS Safari 不给带声或不带 inline 的视频自动播放（实测桌面 Chrome `paused=false`、`readyState=4`）。

- **`llm/0002` 嵌同系列的第 2 段动画，位置照 `llm/0001` 那条判据走**（2026-10-08 学习者给素材）。`assets/llm-prefill-decode.mp4`（1280×720 / 74 秒 / 5.8MB）＋ `llm-prefill-decode-poster.png`，仍是从同内容 gif（854×480 / 887 帧 / 9.5MB）抽帧。**位置在 `note` 之后、§1 之前**，理由同上条：底部字幕就是全课压缩版（"prefill 一次填满货架；decode 每次只送一行，却要扫整份货架"），`note` 已把「第 1 轮 = prefill，后面每轮 = decode」立住，读者知道该盯什么。mp4-over-gif、`muted`+`playsinline`、`base.css` 三条也照旧。
  - **poster 取第 780 帧**：「5 轮完成」态——七站齐全、货架攒满 8 格、回答框「我是 AI 助手」、底部字幕正是结论句。**带放大浮层的帧（Block 放大讲 prefill / decode）会把整条链盖住**，同样不取。
  - **图注只补"动画与课内文字对不上"的两处**：①「第 N 轮 / 5」的"轮"要 §2 才正式定义 → 图注当场给一句"＝整条流水线已经完整走了几遍"（1.5「定义在后面和没定义一样」）；② 本课没有七站编号，点明"跟第 1 课那段动画是同一套七格"，防读者拿第 1 课总图的九站去对（两段动画的七格**逐格一致**，已抽帧比对）。货架"实际每层各存一份 k、v"动画自己印在画面上，图注不重复（1.5 第 1 问）。
  - **实测**：`readyState=4`、解码 1280×720、渲染 704×396（正好是 44rem 正文栏）；`paused=true` 是**标签页 hidden 被浏览器挂起**（`document.hidden=true` 时 `play()` 后 currentTime 仍在走），不是没自动播。
