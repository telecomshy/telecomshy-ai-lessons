学习者从"向量怎么表示文字"起手，逐轮打磨出一个外星人比喻（高维字典 → 每字一点 → 点被上下文推着挪 → 拿落点跟字典比对挑点），最后自己定位：**它不光是向量的比喻，是整个系统的全景画，要放在开头给读者直观印象**。比喻的中间版还带出两轮真问题：「向量数字大小表示什么」（坐标值；轴没有名字，含义只在向量间的关系里）、「静态 embedding 怎么会被'推一把'」（**石板不动、浮标动**——嵌入表固定，hidden state 才被上下文改写）——这两个答案留在对话里，**不进课件**（0000 的读者不需要，0001-deep Q8/Q11 已有家）。

- **落点 `0000` §1 末尾（追问框之前），三条根据**：① 副标题承诺的"先弄清大模型**作为程序是怎么回事**"此前一直悬空，比喻正好兑现它；② 284/292 的判例——**压缩版全景放"读详细之前"＝"先看短的再读详细"，是正确用法**，放详细内容之后才是占注意力两遍；③ 比喻结尾一句"不是人填的，是学出来的"正好接住 §2–§3 训练主线，**从"外挂"变成钩子**。判据：**插进主线课的画面，结尾必须交棒给主线**，否则就是 5.16.2 那种补丁。
- **三处修整落地**：「字典」钉成**嵌入表**（`0001` Q1 有"词表**不是**解释意思的词典"，不钉会错映射）；「（对应注意力层）（对于FFN）」从故事里拿掉、收进结尾对表括号（1.5"定义在后面＝没定义"；对表括号是**预告**不是使用，可留）；错别字（二是→而是、对于→对应）。学习者口径：**比喻生动优先、不必逐句对应机制**，精细术语（"赔率表/画像"）反而削弱效果——已回写进「2. 学习者画像」。
- **被否掉的两个去处**：进阶版 Q12（**一个比喻只用一次**，家在 0000 就别在 0001-deep 再养一份）；基础课 `0001` 正文整段（263"三个必须记住的画面"判例——每节末要收住，不是再开新概念）。
- **连带三处**：`0001` §1 向量 bullet 加一句回指（"第 0 课比喻里'字典上的坐标'就是这一行"——比喻要有回报；按 680 回 0000 核过措辞）；追问框开头改"长什么样？"→"画里每一步到底怎么做到的？"（问题被答掉一半，1.5 之二同一次改掉）；**标题不动**——改名牵连跨页引用，5.7"锚点活着、名字死了"：**没有收益的名字不要动**。

## 5.19.1 比喻进正文、导论去重（同日第二轮，学习者定）

学习者两条：**「比喻要优先放正文，注释只放不影响阅读的术语解释、或会打断阅读的知识点」**＋**「导论有重复的描述，整个课件作为整体要读得顺畅」**。注释框规矩已进 1.5。

- **比喻从 `note` 框改回正文**，引导句照学习者给的样式："**那么整个系统大概是什么样子呢？你可以想象有个外星种族，他们的文字和我们不一样……**"；机制对表留灰字括号（正合"注释只放术语解释"）。判据补进 1.5：**比喻是叙事，归正文；注释是旁注，不归叙事**。
- **去重清单（概念级，逐处消掉）**：① 四步链在钩子和主线 note 相邻说了两遍 → 钩子只留"就四步"，链的名字交给 note（它是 §3 挂回的锚）；② "普通程序 vs 大模型"三遍（钩子 / §1 正文 / pillars 对比块）→ §1 那段压成对比块的引导句；③ "确实是程序"钩子与 §1 各一遍 → §1 换说法不复读；④ 权重定义 §1、§2 各一遍 → §2 开头只补"参数＝同义词"；⑤ "唯一的东西/只有一样东西"三遍 → 留 §1 那处；⑥ 主线句 note 与追问框各一遍 → 并进"第二个问题"那句。**判据：钩子可以预告正文，但正文同一句话不许说两遍；一句话删掉后读者什么都不缺，它就是复读。**
- **连带**：比喻结尾不再说"不是人填的"（钩子原话，改用"两个问题没交代"引出课链框＋主线）；追问框瘦身成纯课链（问句上提正文、主线句下移正文）。
- ⚠ **注意范围**：本轮只去了 `0000` 的重复。**"注释框只装两类"是全库新规矩**，其余各课的 `note` 框还没按它过——待办见 4.1。
