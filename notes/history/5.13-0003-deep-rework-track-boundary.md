## 5.13.1 落点分界线（这条最该写进 1.3）

学习者提出"agent 的内容是不是该放到 agent 课／技巧课"。核对下来 **LLM 轨道 12 个文件里有 89 处 agent 相关内容**，但按下面的线只有 **7 处**该搬：

> **这条的答案在模型 / 服务端 → LLM 轨道（地基）；这条的答案在你的代码里 → 技巧篇（做法）。**

- **不要按"话题"分，按"落点"分。** `NOTES.md` 第 3 节给 LLM 轨道的定位就是"只讲**影响 agent 成本 / 延迟 / 设计**的机制"——所以"不许提 agent"和"为 agent 打基础"本来就不矛盾。**把凡是提到 agent 的都搬走，LLM 轨道就变成一本通用 LLM 教材，与 mission 脱钩。**
- **判据的可操作形式**：问一句「删掉这条，agent 作者会不会写不出正确的 agent？」——**会**＝地基，留；**不会，只是做起来更省事 / 更稳**＝搬。
- **该留的例证**（都有出处，别急着搬）：`0006` 「格式敏感的活掉得最多」是**能力从哪来**（第 3 节明写 LLM 轨道兼讲"能力与失效的来源"）；`0007` 「R1 论文自己说 cannot leverage tools」是 5.6 有意留下的落点；`0002` 「agent 基本都是读多写少型」是由 prefill/decode 推出的**结论**，而且那句自己就写了"这里不展开讲啦"；`0001-deep` 里 agent 请求装什么，是 5.8 记着**学习者拍板**放进 Q9 的。
- **该搬的例证**：`0003-deep` 并发那条 note 的做法半边 ＋ Q4 那条"好消息 agent 基本碰不到"、`0003` §5 末句、`0006` 整个 `.goal`「对 agent 有这么一条」、`0007`「拿自己的活去测工具调用」、`0005`「都要自己跑一遍才知道」、`0004`「对你的 agent 的启示」。

## 5.13.2 下沉按"一课一课"做，别一次性大搬迁

学习者选了"**只做 0003，先收口这一课**"。理由是 5.2 已有先例（`0004` §5「工业界三大招」整节下沉 ＋ **连带必须改钩子**）：每步能单独核验、单独回滚。**判据：跨课搬内容，一次搬一课**——搬完立刻跑 `progress.ps1`，别攒到最后。

- **`practice/0001` 接住了**：新增 `§6 技巧五：同一段前缀，别并发着发`（做法／理由／反例／什么时候不适用，配齐 1.3 要求的三件套），`§6～§10` 重编号。**动之前先查两件事**：全库有没有指进这一页的**锚点**、页内有没有引用**节号** —— 两条都为零才敢重编号。
- **拆的时候按落点切成两半，不是整条搬**：并发那条 note 里，「缓存条目要等第一个响应开始才可用」是**机制**（留 LLM），「等第一个响应回来再发」是**做法**（搬技巧篇）。**判据：一条 note 往往横跨两半，搬之前先按分界线切，别整条动。**
- **搬走之后 LLM 那边要留一句指路**，否则读者看到"撞不上"却拿不到办法。方向只能是**基础课/进阶版 → 技巧篇**（1.4 明令进阶版不许往回指基础课）。

## 5.13.3 「问题本身没问对」比「答案写错」更靠前

Q3 原来叫《既然便宜 10 倍，那"缓存写入"为什么还要加钱？》，学习者直接回：**"这个问题我就没看明白，什么叫缓存写入要加钱？"**

- **根因**：那个标题**预设了读者已经接受的错误模型**——好像缓存是一块硬盘、把东西放进去要交保管费。答案是："缓存不是硬盘；第一次写进去时那次请求的 prefill 一点没少跑。" **一个把读者带错的问题，正文答得再对也没用。**
- **判据：拟题之后自问一句"读者会把这题理解成在问什么"**——和我理解的是不是同一件事？不一样就是题错了，**不是答案错了**。
- 改后：《缓存到底省了什么？第一次用会不会更贵？》——从读者会问的那句出发。

## 5.13.4 一手资料会变旧：厂商行为断言要写清"对谁成立"

本轮查证发现进阶版 Q2 那条 note **已经过时**：它写"推理模型不带回思考内容是缓存失效的**头号原因**"，而按 Anthropic 现行文档，**Opus 4.5+ / Sonnet 4.6+ 默认保留** thinking blocks、缓存不受影响；只有更早的 Opus/Sonnet 和全部 Haiku 会被剥除。

- **判据：凡"某某是某某的头号原因"这种**厂商行为断言**，落笔前确认它对**当前所有版本**都成立；不成立就在 `RESOURCES.md` 里写清"这条只对谁成立"，别让它进正文当通例。**
- 这正是 1.4 那句"主动写的『四个别误会』反而最容易过时"的一个实例——**过时的不是被追问出来的理解型内容，是没人追问的断言**。
- 顺带一条更新纪律：`platform.claude.com` 直连回 "App unavailable in region"（1.1 记过），**带 `-Proxy http://127.0.0.1:7890` 能拿到完整正文**——所以"抓不到"要分清是真抓不到还是被地区挡了。

## 5.13.5 学习者把一个问题拆成三个子问题时，答案可能分居两地

并发那条，学习者问的是三个子问题：**归谁决定 / 客户端会不会自动带 / 怎么确认命中**。查完发现前两个是机制（留 LLM），第三个的**用法**（你的程序该怎么配合）是工程做法（搬技巧篇）。

- **判据：把学习者的三个子问题逐个落到"答案在谁手里"，往往会发现它们分属两节** —— 这比先决定"这题归哪课"更准，也顺手解决了"答案在两处要不要写两遍"。
- **不确定的地方要标出来**：网页版聊天与 harness 会不会自动带回思考块，**没有任何产品文档说明**。课里写成推论并标明"**这是从『不带就报错』推出来的，不是对某个产品的实测**"（1.1：绝不凭记忆补）。**能从规则推出的结论可以用，但必须让它看起来像推论。**

## 5.13.6 逐字重复 ≠ 重复

`tools/overlap-audit.py`（本轮新建）：逐行抽两页可见文字 → 排除页脚/互链/资料出处 → 取每对行的最长公共子串。**它给出的逐字命中（≥9 字）只有 2 处**，但**概念级重复有 13 处**。

- **判据：报"两页有 N 处重复"之前，先分清是逐字还是注意力** —— 1.5 第 1 问说了"重复不是同一句写了两遍，是读者的注意力被占了两遍"。**逐字命中低不代表不用改**，所以机械扫描只用来**定位**，定性还得逐处读（5.4「正则只用来定位，不用来定性」）。
- **工具自身也踩过坑**：第一版用滑窗找共享子串，同一段长话**每个偏移都报一遍**，173 条里 170 条是垃圾。改成 difflib 求**最长公共子串**再按行号去重，才降到 25 条。**判据：写"找重复"的工具，先看它会不会把一处重复报成 N 处**——否则你会被自己的工具带着跑偏。
