课程目录

一个 mission，四条轨道。各轨独立编号，可以分开翻。

怎么读这个目录

这个仓库只有一个目标：搞懂 AI Agent 的原理与工程。但课程分成四条轨道——

LLM 底层只讲"影响 agent 成本 / 延迟 / 设计"的机制，以及能力和失效的来源；Agent 原理篇直接服务这个目标（是什么、为什么）；Agent 技巧篇讲"怎么做、怎么不翻车"（上下文工程、工具设计、失败模式）；RAG讲"怎么让模型用上手边没有的信息"，只讲机制与取舍。

四条轨道各自从 0001 编号，所以提课号时要说清轨道，例如「LLM 底层第 3 课」。轨道之间用超链接互相打通。

课程是AI 先生成、我再逐课修改的，进度分三档：标题后带 completed 的是已经改过一遍的；普通卡片是还在改；虚线卡片标着「下一步开」的还没写。带标记的课可以直接照着读。

LLM 底层

只讲影响 agent 成本 / 延迟 / 设计的机制，以及能力与失效的来源。教材放在 lessons/llm/。基础课给初学者和业务人员，进阶版给技术读者。

基础课 —— 给初学者和业务人员。给结论和直觉，不给推导和算式。

0000 · 模型是怎么学出来的completed

先导课，先读这个：大模型作为程序为什么多一个训练阶段，那些数字是哪来的、怎么被调的，以及为什么它天生只会「接下一个字」。

动手：exercises/llm/0000-how-models-learn.py

0001 · 从「token」到「下一个 token」completed

基石课：文字 → token → 向量 → 注意力 → FFN → 采样，看懂全貌。

动手：exercises/llm/0001-tiny-attention.py　·　exercises/llm/0001-sampling-params.py

0002 · 一次请求的两段：prefill 与 decodecompleted

为什么「读长文」快、「写长文」慢。顺带钉死一次请求 / 一轮 / 层。

动手：exercises/llm/0002-prefill-vs-decode.py

0003 · KV Cache 与「缓存命中」是两回事completed

请求内算过的别重算，跨请求接着用。本课实测：只改开头一处，成本差 3.7 倍。

动手：exercises/llm/0003-cache-hit-simulator.py

0004 · 一趟装满的卡车completed

排队 ＋ 拼车：一张卡怎么同时服务几百个人。用一点点延迟，换几十倍吞吐。

动手：exercises/llm/0004-batching.py

0005 · 它真的在思考吗？completed

屏幕上那段「思考」，是真在想还是演给你看？它确实在打草稿——但草稿不是它的想法，还按字收钱。

动手：exercises/llm/0005-reasoning-cost.py

0006 · 量化：把模型压小，把字吐快

压小 = 吐字快，但读长文一点不快。附实测：同一台机器，只改存法。

动手：exercises/llm/0006-quantization.py

0007 · 蒸馏：小模型的本事从哪来

教小模型时你给它什么，它就只能学到什么。附实测：只搬答案是最差的一档。

动手：exercises/llm/0007-distillation.py

0008 · 这件事到底是谁干的

四层归属表：哪些本事是引擎给的，不是模型的。附四条 agent 侧的坑。

动手：exercises/llm/0008-who-does-what.py

进阶版 —— 给想动手验算的技术读者。装的是基础课没讲的那部分理由，不是加强版；按需跳读，读基础课遇到括号链接就能直达。

初学版讲「是什么」，这篇答「为什么 / 还有什么坑」。

0002 进阶 · 里面到底在转什么completed

初学版讲「两回事」，这篇答「具体到多轮、到工具、到断点，又是怎样」。

0004 进阶 · 批从哪来、拐点、工业界的招completed

初学版讲「怎么排队、怎么拼车」，这篇答「批从哪儿来、什么时候到头、工业界怎么绕过去」。

0005 进阶 · 谁写的、怎么切的、谁收着、怎么练出来的completed

初学版讲「那段思考是什么、值不值」，这篇答「那段字谁写的、边界谁切的、签名收着什么、它怎么练出来的」。

0006 进阶 · 压法是什么、KV 是什么精度

初学版讲「量化是什么、会掉什么」，这篇答「压法是什么、AWQ／GPTQ 各怎么压、int4 的模型 KV 存多少位」。

Agent 原理篇

是什么、为什么：怎么让模型自己决定下一步、动手、看结果。教材放在 lessons/agent/。

0002 · 模型只能吐字，它怎么「伸手」做事？

0003 · 把零件装起来：一个真的 agent

exercises/agent/0003-mini-agent.py

0004 · 换上真模型，假的骗了你哪些地方

exercises/agent/0004-real-model-agent.py

0005 · 工具长出两个新形状：MCP 与 Skill

0006 · Harness：你天天在用，却没分清的那个词

RAG

只讲机制与取舍：为什么要检索、一条链六步各在干什么、什么时候不该上。不讲向量库选型 / 产品对比（会烂，也超出这份教程的使命）。教材放在 lessons/rag/。

基础课 —— 给初学者和业务人员。给结论和直觉，不给推导和算式。

0001 · 为什么得「先查资料再回答」

模型不知道你的数据，是因为信息不在它手边，不是因为它笨。RAG ＝ 先替它翻书。

动手：exercises/rag/0001-why-retrieval.py　·　0001-sparse-vs-dense.py

0002 · 一条 RAG 链长什么样

切块 → 变向量 → 存 → 查 → 塞进提示词 → 生成。六步里只有最后一步是模型。

动手：exercises/rag/0002-rag-pipeline.py　·　0002-chunking.py

0003 · 什么时候不该上 RAG

「我有文档 → 上 RAG」这个反应，一半时候是错的。要精确值、要实时、要推理，都别上。

动手：exercises/rag/0003-when-not-to-use-rag.py

0004 · 两种典型翻车

该来的没来 vs 来了但没用上——解法正好相反，先分清再动手。

动手：exercises/rag/0004-two-failure-modes.py　·　0004-rag-eval.py
