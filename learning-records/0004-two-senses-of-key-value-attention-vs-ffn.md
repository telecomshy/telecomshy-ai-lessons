# 能区分两种「键值」：注意力的 K/V（可缓存）与 FFN 的键值记忆（是比喻）

学习者在 `0002`（prefill 与 decode）的 decode 一节里，抓住了一处措辞的连带后果：「每一层都有 KV，那**除了注意力层，FFN 也有吗**？」——他注意到"每一层"是全称，会顺带把 FFN 卷进来，于是主动去问 FFN 有没有同样的东西。

答案是**没有**，理由是机制性的：KV cache 里的 K/V 只属于**注意力**那一步算出来的量。**FFN 不回头翻历史**——它逐位置处理，每一行各走各的——所以没有"要复用的东西"，也就没有缓存可言。

他顺带碰到了「键值」的**同词不同义**：Geva et al.（EMNLP 2021）发现 FFN 层运作起来"像"一张**键值记忆**——键对应训练语料里的**文本模式**，值对应**输出词表上的一个分布**（原例：前文 `Eiffel Tower is located in` 触发一条记忆，把「Paris」的分往上推）。那是**解释它怎么工作的比喻**，不是缓存；两者只是恰好都用了"键值"两个字。

**Evidence**：由 `0002` 里"每一层都有一个货架"一句触发。核对一手来源：Geva et al. 2021 摘要原文 —— "feed-forward layers … operate as **key-value memories**, where each key correlates with textual patterns in the training examples, and each value induces a distribution over the output vocabulary"。同时，初学版第 1 课已确立"只有注意力那一步互相看，FFN 那一步各走各的"，两条合起来就足以否定"FFN 也有可缓存的 K/V"。与他此前的 **LR-0003**（注意力的不对称：Q 一次性、K/V 可复用）属**同一族**追问——都在问"这个量的来源与生命周期"。

**Implications**：
- 「注意力的 K/V」与「FFN 的键值记忆」**必须显式区分**。"每一层都有 K/V"这句话本身没错，但会被顺理成章地误套到 FFN 上。已在 `0002` decode 一节加了专门的 note，并链到 `0001-deep` 的 Q5。
- 这是**第三次**出现"来源与生命周期"型追问（LR-0003 占两次、本次一次）。所以讲任何机制时，**默认**要交代四件事：这个量谁算的、存不存、什么时候被读、读完去哪。
- 讲多层结构时，**"每一层"这类全称措辞要当心**——他会逐层检查它是不是真的对每一层都成立。
