# 能独立推导无缓存时的重复计算量（1+2+…+N）

学习者在没有被直接告知的情况下，自己推出了自回归生成在「无 KV Cache」时的重复计算模式：第 j 步要把前 j 个 token 全部重算一遍，因此**越靠前的 token 被重算次数越多**（第 1 个被算 N 遍），总量为 `N(N+1)/2`——100 个 token 对应 5050 次计算。这把「平方级浪费」从一个结论变成了他自己的推导。

**Evidence**：学习者主动提问并自行推演「蹦第 1 个算 1 次、蹦第 2 个第 1 个又算一遍、蹦第 3 个第 1 个算第三遍 / 第 2 个第二遍……」，结论正确；我逐条核对无误。

**Implications**：注意力与 KV cache 的**机械原理**这一层已经站住。后续可以**直接进入应用层**——prefill 与 decode 的分工、批处理、推理优化（PagedAttention、用显存换速度）、以及前缀缓存的工程用法——不必再回头铺垫原理。另外确认一条学习画像：该学习者对「机制 + 数量关系」敏感，讲工程取舍时**应尽量带出量级计算**，否则容易觉得没讲到点上。
