③ 基准尺子：LoCoMo 与 LongMemEval

  • LoCoMo（ACL 2024）：10 段跨会话长对话、约 2000 道题，考单跳、多跳、时间、开放域等。老牌尺子，如今多数系统都能考到 80 分上下，区分度在下降。
  • LongMemEval（ICLR 2025）：500 道题、单档最多 500 个会话，把"记得好"拆成五个能力：信息提取、跨会话串联、时间推理、知识更新、该说不知道。S 档约 115k token，M 档约 150 万。
  • 共同的盲区：两把尺子都出在"聊天助手"场景；客服工单、代码仓库、文档协作这类形态，分数只能当门槛。最终验收还是那句：拿你自己的 20 个真实问题去测（测法见技巧篇 0006 第 3 节）。

④ 怎么用这张表

先答四个问题，再回来对号入座：① 你要记的是哪种东西？（偏好和事实 → 条目式；事情的经过 → 事件式；做过的流程 → 技能库）② 改口之后，要不要还能答"当时是什么"？（要 → 留痕式；不要 → 覆盖式就够）③ 数据放哪？（合规、内网要求 → 可自托管或自己写；个人日常用 → harness 自带就够）④ 取回的 token 预算紧不紧？（紧 → 选"只取相关几条"的方案）。拿不准就先用"自己写"——它永远能升级到产品，反过来不行。
