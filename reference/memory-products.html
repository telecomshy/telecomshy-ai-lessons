③ 四款产品怎么落：存·取·管

这张表答的是「四家具体长什么样」（细节按 2026-10-18 的文档抓，会变；原理在 Agent 篇 · 第 1 课 · 记忆）。和上面六方案表是两把尺：那张答「选哪类」，这张答「同类能差多远」。

产品 存什么、存哪 怎么取 怎么管
OpenCode 不自动存；AGENTS.md／CLAUDE.md＋代码库 每次会话读规则文件 你手改；没有自动遗忘
TeleAgent（自述） USER.md／MEMORY.md／daily-log，Markdown 文件 前两个常驻注入；日志关键词/正则、按名读 改口留痕：旧条目标过期不删；日志按时间衰减
Supermemory 文档→块＋记忆图＋profile；事实/偏好/经历 search；profile；可带 related 边 自动：矛盾更新、时间过期、噪音过滤；也可显式 forget/update
Mem0 对话抽成事实；SQL＋向量＋实体库 语义/关键词/实体/时间多路打分 默认追加；改/删显式 update/delete

三句值得记的：

  • 不存也是一种设计：OpenCode 不内置长期记忆不是缺陷——写代码的活，状态本来就该在文件和 git 里。
  • 记忆可以就是文件：TeleAgent 没有"记忆数据库"，就是几份 Markdown 加一段取回程序；改口留痕——旧条目标过期不删，问"以前爱坐哪"还答得出（此条为产品自述，官方手册无载）。
  • Supermemory 的记忆图会自己长大：新事实更新旧事实（updates）、补充细节（extends）、推断你没明说的（derives），按事实／偏好／经历分三类且寿命不同，没用的自动遗忘（时间过期、被推翻、噪音过滤）。

各家文档（2026-10-18 抓）：OpenCode 规则文件 · Supermemory — how it works ／ graph memory · Mem0 — how it works（论文四动作与产品口径的差异见上表 Mem0 行）· TeleAgent 记忆细节为产品自述，暂无公开文档。

④ 基准尺子：LoCoMo 与 LongMemEval

  • LoCoMo（ACL 2024）：10 段跨会话长对话、约 2000 道题，考单跳、多跳、时间、开放域等。老牌尺子，如今多数系统都能考到 80 分上下，区分度在下降。
  • LongMemEval（ICLR 2025）：500 道题、单档最多 500 个会话，把"记得好"拆成五个能力：信息提取、跨会话串联、时间推理、知识更新、该说不知道。S 档约 115k token，M 档约 150 万。
  • 共同的盲区：两把尺子都出在"聊天助手"场景；客服工单、代码仓库、文档协作这类形态，分数只能当门槛。最终验收还是那句：拿你自己的 20 个真实问题去测（测法见速查 · Agent 验收自查）。

⑤ 怎么用这张表

先答四个问题，再回来对号入座：① 你要记的是哪种东西？（偏好和事实 → 条目式；事情的经过 → 事件式；做过的流程 → 技能库）② 改口之后，要不要还能答"当时是什么"？（要 → 留痕式；不要 → 覆盖式就够）③ 数据放哪？（合规、内网要求 → 可自托管或自己写；个人日常用 → harness 自带就够）④ 取回的 token 预算紧不紧？（紧 → 选"只取相关几条"的方案）。拿不准就先用"自己写"——它永远能升级到产品，反过来不行。
