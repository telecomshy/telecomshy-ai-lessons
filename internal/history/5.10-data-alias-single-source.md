# 5.10 别名收成单一落点 `data-alias`（2026-10-05）

> 本文件是 `NOTES.md` 第 5 节「决策与教训存档」的原文搬移（内容未改），供「当初为什么这么定」被质疑时查阅。回 [NOTES.md](../../NOTES.md)。

---


起因是查 4.2 那条"标题与别名对不上"，结果查出一个**更硬的错**：`llm/0001-deep` 早就是 **11 问**（5.8 把「附 · 五个别误会」转正成 Q11 那轮），而**六个落点有五个还写着"十"**：`<title>` · `<h1>` · 基础课那句"同课进阶" · 目录页卡片 · README 两处。**这是 5.9 自己写的教训「改数字要 grep 页面自己的标题，外链审计抓不到」第二次没做到** —— 上一次是 `0003-deep` 的"五个→六个"。

- **落点比预想的多一个。** 动手前我只想到四处（title / h1 / 卡片 / README），实际第六处在**基础课 `llm/0001.html` 的"同课进阶"行**里，压根不在进阶版这个文件上。**判据：一个名字有几处落点，先 `grep` 出来数，别照着自己记得的位置写清单**（与 5.4「报数量之前先全库扫」同源）。
- **别名的权威侧＝已发布的卡片/README，不是 `<title>`。** 别名已经在 GitHub Pages 上、是对外 URL 邻居，改它成本高；`<title>` 只是浏览器标签页，改零风险。**但 h1 不跟着别名走** —— h1 是首屏标题，可以更完整（`rag/0002-deep` 就是别名短「切块到底切多大」、h1 全「切块到底切多大、重叠多少、按什么边界切」）。所以只统一 **title ↔ 别名**，h1 保留自己的话。
- **根治：`<div class="lesson-meta" data-alias="…">` 作唯一落点**，卡片 / `<title>` / README 三处都从它派生。新增 **audit E 段**核这三处相等，`progress.ps1` 那条"进阶版 README 条目不自动写"的限制因此撤销。**改别名从此只有一处要改。**
  - **新写一段脚本，就必须按 5.4 在副本上跑字节级往返测试**，不能拿真仓库试。实测抓到一个只看输出会漏的 bug：README 的每个 row 都自带换行符，`$rows[$hit] + $frag` 会把片段甩到**下一行**去；而 audit 的清单块只认「`- ` 开头」的行 —— 于是链接明明写进去了，却被判「README 缺」。**判据：往按行切出来的数组里插内容，先把该行的行尾换行符摘下来、插完放回去。**
- ~~**E 段管不了"数字对不对"**~~ **已由 5.11 补上**：E 段现在也核别名开头的数字与实际问数、以及 Q 编号连续性。
