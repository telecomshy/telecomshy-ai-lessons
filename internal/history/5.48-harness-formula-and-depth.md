# 5.48 0005 补回公式并加厚：五子系统、长任务、任务-壳匹配

- 日期：2026-10-18
- 触发：学习者指出 0005 把 **Agent = Model + Harness** 删掉了，而这个公式很重要；同时觉得 0005 内容仍太单薄，要求借鉴其它 harness 课程/教程充实。
- 结论：保留四款产品对照，但把它从"主角"降为其中一节；前面补公式、五子系统、长任务、任务-壳匹配。

## 新增内容

1. **§1 公式与责任线**：
   - 恢复并放大 `Agent ＝ Model（LLM）＋ Harness`；
   - Model vs Harness 对照表（负责什么/换掉它/出事先看）；
   - 三条日常解释（同模型换壳、别冤枉模型、选产品本质是选壳）；
   - 边界：harness 不能把弱模型变强，只能把强模型用充分或用废。
2. **§3 五个子系统**（借鉴 Learn Harness Engineering）：
   - Instructions / State / Verification / Scope / Session Lifecycle；
   - 每个子系统：管什么/缺了会怎样/产品里的影子；
   - 点明"功能表不写，但体验差在这里"。
3. **§4 长任务跨会话**（借鉴 Anthropic 长任务 harness）：
   - initializer agent + coding agent；
   - feature list / init.sh / progress / git commit；
   - 每次先读状态、只推一个 feature、端到端测试、干净收尾；
   - 四类翻车：一口吃成、过早宣布完成、留烂摊子、没测就说完成。
4. **§5 task-harness fit**（借鉴 LangChain）：
   - 没有"最好的 harness"；任务需要的上下文/失败/策略/环境不同；
   - 写代码/办公文档/常驻助理/长任务四类任务对照。
5. **小测 8→12 题**：加公式、五个子系统、长任务、task-harness fit、公式边界；产品场景保留。
6. 来源补：Anthropic 长任务 harness、LangChain custom harness、Learn Harness Engineering（GitHub/文档站）；产品文档仍用官方。
