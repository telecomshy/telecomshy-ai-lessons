## 为什么不合并（对表后的事实）

- **`0006` 的核心零件依赖它的位置**：「对号入座」表是把前五课映射进 harness 零件，只能排在 `0005` 之后；并进第 1 课时读者还没学过 2～5 课，这张表（那课的"啊哈时刻"）无处安放。
- **0001 并不薄**：5.25 扩写后它是 agent 轨最厚的一课（8 节＋5 题＋动手）。真正的问题是**两课抢同一个"什么是 agent"**——那是边界没划清，不是体量问题。
- **两课各有一个性质不同的动手**（跑通最小循环 vs 盘点 harness），合并＝一课两个动手，不合 1.2。
- **概念顺序**：harness 零件清单要靠 0002～0005 才立得住，在第 1 课只能讲成干定义。
- 5.25 记着同一个张力（"agent = harness + LLM 的困扰"）当时用「差量口径＋前引」接平——**这次确认接平不够，根治办法是把定义整块搬进 0001**。

## 调换 6/7 的三条理由

1. **对号入座表原来缺一角**：7 行里没有记忆——因为当时记忆课排在 harness 后面。总装课收到最后，六课全进表，三柱齐了再收网。
2. **"骨架闭合"的收口本来就写在 0006 §8**，却把记忆说成"往深走的四条线之一"，跟 0001 三柱的地位打架。记忆前移＝零件课，收尾＝总装，各自归位。
3. 外部课程同款递进（零件→总装）：Agent Harness Engineering（Loop→零件→Teams→Production）、HuggingFace Agents Course（Fundamentals→…→Final project）。
4. **调换比合并便宜**：课数不变（7→7），主页计数不动；只动两组文件名＋脚本名＋约 15 处入链。
