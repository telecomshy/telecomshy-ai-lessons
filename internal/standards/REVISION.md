# 改课与精修标准

> 适用：任何已有课的修改（改文字、改结构、改事实、整课重过）。新建课看 [`PROCESS.md`](PROCESS.md) 第 3 节＋[`COURSE-STANDARD.md`](COURSE-STANDARD.md)。
> 2026-11-17 从 `NEXT-SESSION.md` 的精修流程与 `COURSE-STANDARD.md` 1.5「改课」条抽出：开发与修改分开，各自只有一个落点。

## 1. 文字底稿是 md

- **正文只改 [`lessons-md/`](../../lessons-md/) 的对应 md，不直接改 HTML。** 回写约定见 [`lessons-md/README.md`](../../lessons-md/README.md)。
- 学习者手改 md，或由 agent 按 [`ARTICLE-STYLE.md`](ARTICLE-STYLE.md) 重写 md；主代理负责回写 `lessons/<轨道>/<课>.html`。
- 回写只做表现层映射，不改学习者的说法：`**`→`<b>`、字段与命令→`<code>`、小测→`.quiz`、UI 文字加「」并加粗、节号重排并同步正文里的「第 N 节」引用、图与 alt 不动、图注随稿。
- **结构改动也先落 md**，再连同 HTML 的锚点、互链、样式一起回写；不要只改 HTML 留下一份对不上的 md。

## 2. 单篇精修流程

1. **取稿**：学习者交回 md，或按点名由 agent 重写。重写前先读 `ARTICLE-STYLE.md`，改的是文字，不是页面结构。**不读前后课抄语感**；机制口径由主代在回写时对表。
2. **对拍**：逐段比对交回稿与上一版，列出哪些段动了、哪些是新事实断言。
3. **备份**：`lessons/<轨道>/<课>.html` → `backup/<轨道>/<课>.html`（只有 agent／llm／rag 三个子目录，同名覆盖，存回写前原件）。
4. **映射回 HTML**：见第 1 节的表现层规则。
5. **新事实**：当场抓一手来源＋抓取日期，补进课件一手资料框和 `RESOURCES.md`（含索引行）。抓不到记进 `RESOURCES.md` 的 Gaps，不编造、不留空引。
6. **口径自查**：机制说法与前后课一致，术语表同步，裸「官方」注明哪家，弯引号与属性直引号，markdown 残留，每题恰好一个 ✅。
7. **核验**：`check-links.py` ＋ `progress.ps1` audit ＋ `html2md --check`（只读；**永远别跑全量转换**，会覆盖未交回的 md）＋ HTML 专项对账（小测反馈、选项逐字对 md）。
8. **报告**：落盘清单、核验结果、下一步；请学习者 F5 验收页面。

## 3. 基于整篇，不打局部补丁

- 改课前先**通读本课全文**＋前后相邻课＋对应参考卡，不只改被指出的那段——局部修改最容易留下前后矛盾、重复解释或断掉的回指。
- 学习者指出一句，那句是**症状**：判断全文还有没有同类问题，**一次改完**，不逐轮挤牙膏。
- 每次修改至少检查六处：开头的承接 · 术语首次出现处 · 贯穿例子 · 表格与图 · 动手与反馈 · 结尾指向下一课。任何一处用了旧说法，同一次改掉。
- 改完用两条标准验收：**遮住小标题仍能读出前后因果**；**前后课不重复、不矛盾**。改到读起来像补丁，就**重写受影响的那一节**，别继续打补丁。
- **点名改课＝整课重过**：补丁清单是输入，不是替代。核查轮只发现小修时，也别把「整课重过」降级成「只改那几处」。

## 4. 核验与边界

- 改完必须过 [`COURSE-STANDARD.md`](COURSE-STANDARD.md) 末尾的交付检查单；机器段跑命令，人工段读文章，两边都过才算交付。
- 没有「定稿课受保护」这一档：任何课都能改，但改前读全文、改后过检查单。
- 不再标 `completed`，也不再维护任何完成徽章或定稿计数。
