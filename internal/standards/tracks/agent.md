# Agent 篇 · 轨道标准

> 写／改本轨任何课前，先读全局 [`../COURSE-STANDARD.md`](../COURSE-STANDARD.md)、[`../ARTICLE-STYLE.md`](../ARTICLE-STYLE.md) 与 [`../PROCESS.md`](../PROCESS.md)，再读本文件。本文件只收 Agent 篇的分版、课型、受众与脚本分层；本轨无 deep 页（全局 1.4 已改为下放说明）。

## 受众（2026-11-17 补）

- 用现成 harness 产品的人，不是框架开发者：会装软件、点界面、照着文档配 key，不要求写代码。
- 对 LLM 有初步了解（用过网页聊天、调过简单 prompt），没系统学过原理。
- 每课按 20 到 30 分钟阅读量写；超出的细节进 `reference/` 或下一课，不塞正文。

## 分版（2026-10-21 学习者定）

- **本轨不分基础/进阶两版**，分课型的轴是**理论｜实操**（meta 行标识：`理论`／`实操`）。
- 理由：本轨的知识点多为判断与生态，「理由本身就是主干」，切不出「薄版」（同一事实没有两档表述）。
- **深度走三条吸收渠道**：**操作深→实操课**（0002 式）、**机制深→LLM 轨互链**、**对照深→`reference/` 速查**。
- **deep 页不预设**：真问题大到三渠道都装不下再定形态（沿革见存档 5.54）。

## 脚本分层（2026-10-18 起）

- **理论课不配脚本**：动手统一放配对的实操课，理论课只在文末指过去。
- **实操课要把「从零能跑」写全**：装哪个包、key 放哪、怎么验通路——安装步骤本身也是课的一部分。
- 「靠代码建的课要逐句检查不跑代码能不能读懂」这条通用规则见全局 1.2 表后段（本轨 0002 即其例）。
