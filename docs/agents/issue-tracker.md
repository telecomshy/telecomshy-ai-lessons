# Issue tracker: GitHub Issues

本仓库的 issue、spec、ticket 都落在 GitHub Issues：`telecomshy/telecomshy-ai-lessons`。

## 约定

- 用 `gh` CLI 操作（已登录）：`gh issue list` / `gh issue view N` / `gh issue create`。
- 读者挑错、内容勘误、改进建议 → 开 issue。标题写清轨道与课号，正文附原文引用。
- PRD 与拆出来的 ticket 也走 GitHub Issues，不在仓库里另建 `.scratch/` 目录。
- 改动落地后在 issue 里回填：改了哪些课、跑了哪些核验。

## 相关入口

- 读者视角的「参与」说明：`README.md`。
- 课程开发规矩：`NOTES.md` 第 1 节。
