## 改中文课件：用什么工具

**优先用会报错的编辑工具；万不得已用脚本，改完必须逐行读回。** 三个已知踩坑：

1. 字符串替换只命中一部分，留下残渣；
2. 正则改写时在 raw 字符串里写了 `\"`，把字面反斜杠写进了 HTML 属性；
3. **带中文参数的 PowerShell 替换脚本**——终端编码会把中文字符弄乱然后**静默写坏文件**（曾把 `0002` 的"读"换成"一"）。

## 改课号 / 对调顺序 / 改名：逐条语义核查

**链接能点、锚点存在，都抓不到这类残留**（文件全在）。步骤：

1. **逐条语义核查"上一课 / 下一课 / 第 N 课"**——别只看 grep 有没有命中，**要逐条读命中行的上下文**（对调那次 grep 已抓到 `0004` 的 5 处却没读，漏了两轮）。
2. **改名同理要全库搜引用**。容易漏的是：链接**文字里的"第 N 课"**、`meta`/`footer` 里的课号、术语表、`docs/learning-records/`、`RESOURCES.md`。
3. **批量替换用中间标记防连带替换**。
