# 5.35 `0009` §6 表格收口句改写：总结句要有一条只属于它的信息（2026-10-17 学习者挑刺）

学习者指着六种练法表下面那句「规律就一句：扣分永远算在「要学的输出」上……提问永远是题面，不是答案。预训练之所以整段都算……」说：**含糊不清、有点绕**——它本来只想做个总结，**改，还是直接删掉？**

- **判定：改，不删。** 这句里有一条**别处没有的信息**：**预训练为什么整段都算**（它没有独立的提问，题和答案从同一段文本切出来）——删了它，表里「整段每个位置都算」那行就悬着没解释（进阶 Q1 的「前文出题、下一个字判卷」在另一版页面，救不了基础课读者）。规律那半是表第三列的收口，留。
- **三处毛病，逐个动刀**：① 「规律就一句」后面跟了**两个分号三个半句**，本身就不是一句；② 「别人写好的回答，或者模型自己现写出来的」是**悬空同位语**（读者得自己猜它是「要学的输出」的举例），而**表格行里本来就写着谁写的**——删；③ 「提问永远是题面，**不是答案**」的后半截是**废话式否定**（"提问不是答案"越解释越糊）——删。
- **改后两句，各管一件事**：规律句＝「挨扣的只有『要它学的输出』，提问只是题面」（把表第三列收成一条）；例外句＝「预训练之所以整段都算，是因为它没有独立的提问——题（前文）和答案（下一个字）本来就是从同一段文本里切出来的」。
- **⭐ 判据（总结句的两条自查）**：**① 这句有没有「只属于它的信息」**——有（预训练的例外解释）就改写留，没有就连句删（与 5.33.18「以总结为名的重复」同族，那条讲删、这条讲怎么留）；**② 句里的同位语举例，先查表格/上文是不是已经给了**——给了就是重复，删；否定式尾巴（「不是 X」）若 X 没在上文出现过，也删。
- **牵连核查（只动一句的前提）**：「要学的输出」全库仅此一处；「提问是题面」在表格行 · 术语表 `#sft` · `0009-deep` Q1 三处照旧，措辞不动。
- **核验**：`check-links.py` OK；`progress.ps1` 全绿；改句读回。

### 5.35.1 同日续：例句末尾「不是变傻了」整句删（学习者：没有人说它会变傻）

学习者指着例句收尾「至于它微调之前本来就懂的，练完还是懂，**不是变傻了**」：**这句可以删掉，没有人说它会变傻。**

- **处置：整句删。** 与 5.34.1③ 同族——**反驳一个没人提出的误读**＝把会话里冒出来的靶子立进了课件（5.33.19 的「没见过的就会乱答」、这句的「会变傻」都是）。删后例 2 回到**纯一根轴**（练到的 vs 没练到的），正是 5.34.1① 要的形状。
- **删整句之前先查它承载的事实落在哪**：「微调之前懂的，练完还是懂」在 `0009-deep` Q7 正面第二条还活着，基础课钩子也有「聪明不聪明是预训练早就定了的」——信息不丢，才敢整句删。「变傻」全库 grep 仅此一处。
- **⚠ 留了一个同形状的没动**：收口句里「不是『不会』，是『没被教』」也是「不是 X」式反驳——但那半句是**学习者本人第一轮点名要的**（5.33.19 起的下半句），本轮没删；要一并删得先问。
- **判据（5.34.1③ 的补充）**：**「不是 X」式句子先问 X 是谁提的**——学习者没提过的 X 就是凭空立靶，删；学习者点名要的 X 保留，哪怕形状一样。
