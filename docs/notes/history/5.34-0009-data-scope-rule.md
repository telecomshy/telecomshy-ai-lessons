# 5.34 `0009` §6「练不出来」改口径：卡住你的不是扣分单，是这轮后训练的数据（2026-10-16 学习者提问）

学习者同一条消息问三件（说的是「第 8 课」，引文逐字落在 `0009-post-training-recipes.html` §6 收口那段，按引文定位）：① **「练不出来」到底啥意思**；② **这里不该说「扣分单」吧，该指「用来后训练的数据」**；③ **后训练数据集比预训练小得多，对模型有什么正面／负面的影响**。

- **⭐ 口径决策（②）：学习者对了一半，改口径成「这轮后训练的数据」，但「扣分单」不删、降级点名。** 一份后训练数据摊开是两半：**出的题（用户会怎么问）只是题面**（SFT 只对回答算扣分，见 5.33）；**当答案／评价的那一半才是真正教进去的**——它就是扣分单。原句「扣分单里没有的信息，练不出来」**只挂在扣分单这一半上**，把「教材／题出到哪儿」那半丢了，读者会拿它推「题没覆盖的场景」。改成两条：**答案／评价里没写的，学不到；题没出过的场景，教了也用不到点子上。** ⚠ 「扣分单」保留为术语（5.33.1 已决定留名），只是把**信息的载体**说成数据——这与全课两轴（扣分单谁出 × 教材谁写）正好对上：**扣分单决定学什么，题出到哪儿决定用到哪儿。**
- **①「练不出来」补定义**：**＝这次训练改不动它**——练完前后模型在这一条上基本原样，不是变好也不是变坏，**不是「不会」，更不是「会答错」**。5.33.19 立的「否定式断言配另一半」照旧（「不是不会，是没被教」保留成句），只是删掉了「这句话只说了……还得配下半句」那句**元叙述**（1.5「不写元叙述铺垫」）。
- **③ 小数据的两面落进 §6 一段「数据少，有两面」**：**好的一面**＝知识底子冲不掉、改的只是行为（微调之前懂的练完还懂）；**坏的一面**＝知识搬不进几个、覆盖窄（没出过的题退回老样子或乱用）、行为改过头把别处带歪（第 3 节 85→45 ＋ Q6）。机制句改成「**它比预训练少好几个数量级（第 3 节那句「写几百到几千条」）→ 少到没力气重写知识底子**」——量级只指回 §3，不重算（1.5「同一件事只量化一次」）。
- **⚠ 一处措辞打架当场对齐**：「冲不掉」（本段）与 `0009-deep` Q6「会被挤掉」不能读成矛盾——**冲不掉的是知识（懂不懂），会被改的是行为（走不往那边走）；练得又久又窄才会把别处的行为挤歪**。所以「好的一面」限定说「知识底子冲不掉，改的只是行为」，「坏的一面」接「改过头还会把别处一起带歪」，与 Q6 的「能力 vs 概率」两分一致。
- **同步落点**：`RESOURCES.md` 那条 Phan et al. 的「用来」指针跟着改词（旧措辞零残留，1.7）；**存档 5.33.19 原文不改**（历史保留当时说法，1.9）。其余全库 grep「扣分单里没有／练不出来／没被教」＝ 0 残留。
- **⭐ 判据（两条）**：
  1. **「X 里没有的，练不出来」这类断言，先问 X 是不是信息的全部载体**——载体是**训练数据**（题＋答案/评价），扣分单只是「教的那一半」；只挂在一半上，读者会拿它去推另一半（题没覆盖的场景）。**判据落点：把句子的 X 换成「数据」再读一遍，看有没有哪一半被漏掉。**
  2. **「练不出来／学不到」这类否定词要给定义**（＝改不动它），否则读者自己填词（填成「不会」就推到「没见过=乱答」）。与 5.33.19 同族，这条管的是**词义**，那条管的是**另一半事实**。
- **核验**：`check-links.py` OK；`progress.ps1` 全绿；§6 改处读回逐行核对；反引号／markdown `**`／属性内双引号残留 grep = 0（三个都 0）。

### 5.34.1 同日二轮：学习者三刺——例句对比错位、开头突兀、「乱答」是别的会话的（整段综合改，不打补丁）

学习者读完上一轮改动后三刺：① **例句「微调之前懂的 vs 微调没覆盖的」是错位对比**，应该是「没覆盖的 vs 覆盖的」；② **开头「『练不出来』是说：……」突兀**——只改这一段、整个问题没综合看；③ **「乱答」是另一个会话的问题**（「不在后训练语料里的问题，模型会不会乱答」），会话问题不该直接进课件。

- **① 对比错位的根**：一句话里塞了**两根对比轴**——「练到的 vs 没练到的」（这次训练教没教）和「微调之前 vs 练完之后」（这次训练伤没伤着），还把两根轴的各一头拼成一对。改法：**例子内部只做「练到的 vs 没练到的」**；「微调之前懂的练完还懂」是另一根轴，用「至于」另起一句。**判据：一句里的对比，两头必须是同一根轴；想说两根轴就拆成两句。**
- **②「突兀」的根：补丁的补丁**。5.33.19 给一句孤句加了下半句，5.34 又给它加了定义——**在一个上文从没引入的词上连打两轮补丁**。根治：让这段**自己带起因**（「选完练法，还要把预期放对」→ 两个例子 → 一句话收口＋指路），孤句警句不再单独立着。**判据：新加的「定义句」如果它定义的词上文没出现过，说明该改的不是词义，是这一段的起因。**
- **③ 会话内容不直接进课件**：「乱答／没见过的和乱答是两件事／它不会凭空编」都是另一条会话线的产物（grep 确认全库只在 §6 一处）。清除「反驳一个误读」的框架，改成**直接描述它实际怎么做**（退回老样子／新规矩用错地方／拿印象凑或答不知道）。**顺带抓出一处真矛盾**：「它**不会凭空编**」跟 §3「没记住的它**照样编**」打架——行为上不乱答、事实上会编，两句本来就该分开。**判据（两条）**：**从会话里搬进课件的句子，先问「它答的是这课的哪个问题」**；**新加的否定句要 grep 一遍跟它打架的旧句**（这次靠通读 Q6＋§3 才抓到）。
- **④「修课件不能只看某一段」当场兑现**：Q6 结尾「回到初学版那句的完整版」回指的是**已经被改掉的那句**——上一轮只改 §6 就漏了它。本轮 Q6 那句改成自足的「说到底：……」＋分工指路。
