学习者指示：第 2 课已经有实操，第 1 课可以不用再脚本演示；第 2 课不用假模型、直接用真模型；"假模型翻车"那几条不要；教程要更详细，从装什么 Python 包、怎么配 API key 一步一步讲。

## 定了什么

1. **`agent/0001` 变纯理论**：删掉第 10 节（跑 `0001-minimal-agent.py`）和第 11 节（挑战），删脚本文件；标题、导读、小测、ask-teacher 同步。理由：0002 就是它的实操配对，两课各跑一个循环＝同一注意力占两遍；0001 那个假模型的动作形状（`{"tool": ...}`）还得在 0002 里重新学一遍真接口。
2. **`agent/0002` 去假模型、直接真模型**：删第一阶段与第 5 节「假模型骗了你哪些地方」五条；脚本改 `openai` SDK ＋ DeepSeek `deepseek-flash`；原"改一改"改成真模型下可复现的三件（`--max-steps 1` 撞护栏／删掉一个城市看工具报错／加一个工具看清单与实现不同步）。
3. **翻车清单换主语**：不是"假模型骗你"，而是"真模型实跑会怎样"——认语义、编工具/填错参数、绕圈/提前收工、花钱和等待、接口格式由厂商定；每张脸都指回代码里的兜底（`fn is None`／`try/except`／`max_steps`／账单／适配层）。
4. **加从零环境章**：Python ≥ 3.10 → venv → `pip install -U openai python-dotenv` → 申请 key → 根目录 `.env` → `--check` 验通路 → 跑四个问题；附错误码表（401／402／429／500／503）与常见坑。
5. **规矩同步**：`NOTES 1.2` 的「动手」行加"Agent 篇理论课不配脚本"；README 的跑脚本说明、目录页两张卡片、`docs/notes/rules/agent-track-redesign.md` §1 表与 §8-2 同步；`.gitignore` 加 `.env`、`.venv/`。

## 为什么

- **受众是"用现成 harness 的人"**（5.40.1 的判断延续）：真开发第一天就是真模型，假模型只是教学脚手架；而假模型的顺利会给出错误预期（它不花钱、不绕圈、不编工具）。
- **理论课与实操课分工要干净**：理论给画面与机制，实操给"从零到跑通"。两课都动手，主线会被安装细节和代码各切一刀。

## 待办与教训

- ⚠ **实测输出必须真跑**：本机 `.env` 未配时脚本按设计报错退出（不静默跳过）；输出待 key 到位后贴进课，逐句对账。
- 环境坑：`pip install --upgrade pip` 在本机卡住近 5 分钟，验证时改用 `uv pip install --python .venv\Scripts\python.exe`；本机 Python 子进程写不了 `lessons/`、`exercises/` 子目录（ACL），改文件用会报错的编辑工具或 PowerShell 的 .NET 写入，并读回核验。
- 中文终端输出先 `chcp 65001`；脚本里的报错走 stderr，贴进课之前要跟屏幕实际顺序对一遍。
