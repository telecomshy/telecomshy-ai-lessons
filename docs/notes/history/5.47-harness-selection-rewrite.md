# 5.47 0005 重写为「Harness 选型」：四款产品对照

- 日期：2026-10-18
- 触发：学习者认为合并后的 0005「内容太少、撑不起来」，且 TeleAgent 单产品拆解「没太多必要，不同 harness 不一样」。选择方案 A：重写成 Harness 工程/选型，不做单产品拆解。
- 明确删掉：原计划的「怎么选、怎么验」正式评估流程（学习者认为用户只凭使用直觉比较）；「自建 vs 现成」（大多数用户不会自己开发）。保留「按场景选」和「隐性成本」，因为直接服务选型。

## 新课结构

1. **一条请求的 6 个环节**：拼上下文 / 调模型 / 执行工具 / 回填观察 / 过护栏 / 记录恢复——每环 harness 在决定什么、用户感知到什么。
2. **6 条设计轴**：形态、默认场景、模型接入、执行环境、扩展方式、默认权限与记忆。
3. **四款产品对照**（官方文档，2026-10-18）：
   - **TeleAgent**：桌面办公；技能广场/MCP；三选一授权+YOLO；定时任务+国内 IM；闭源。
   - **OpenCode**：终端/桌面/IDE 写代码；任意 provider；Agent Skills/MCP/插件；Plan/Build 权限；开源。
   - **Hermes**：CLI/Desktop/服务器；Nous Portal/OpenRouter/任意 endpoint；60+ 工具、7 种终端后端；容器隔离；20+ 消息平台+cron；MIT。
   - **WorkBuddy**：Windows/macOS 办公桌面；内置+自定义/Ollama；文档表格 PPT；Skill Marketplace/Connectors/MCP；Default/Full Access；定时+国内 IM；闭源。
4. **按场景选**：代码/终端→OpenCode；办公交付物→WorkBuddy；国内办公+技能广场+细授权→TeleAgent；常驻多平台→Hermes。强调“不是排名，是默认值”。
5. **功能表之外的三个隐性成本**：工具越多上下文越贵；默认权限就是产品态度；迁移成本（技能/规则/记忆/开源）。
6. 小测 8 题（产品匹配 + 概念 + 功能表边界）。
