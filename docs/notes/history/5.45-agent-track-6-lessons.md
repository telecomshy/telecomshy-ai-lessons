# 5.45 Agent 篇缩成 6 课：删 0004/0006，合并 0005+0007

- 日期：2026-10-18
- 触发：学习者判断「第 4 课内容第 3 课基本包含，可删；第 5 课和第 7 课内容不多，合并成一课分两块；第 6 课手写多 agent 没必要，不如用框架」。
- 结论：**Agent 篇 9 课 → 6 课**，全库重排课号。

## 决策

1. **删原 0004「写一个 skill、接一个 MCP」**：产品级创建/配置已在 0003；文件级脚本不再单独成课。0004 独有的「工具描述五件套」没有丢，压成 0003 §2 的「顺带：工具描述至少写五样」。
2. **删原 0006「编排一群 agent」**：手写 lead＋workers 脚本的演示价值低于用框架；「失败重派是 lead 的活」并进新 0004，「只回结论」本来就在多 agent 理论里。假模型对账「45 字 vs 582 字」随脚本一起删，不保留不可复现的数字。
3. **原 0005「多 agent」＋原 0007「安全」合并成新 0004**：上篇多 agent（何时上、编排者-工作者、派单三件套、token 账、翻车），下篇安全（提示词注入、三个「少」、TeleAgent 授权实证）。两课都短，合成一课反而前后呼应：帮手越多，攻击面越大。
4. **原 0008 Harness → 0005；原 0009 拆解 TeleAgent → 0006**。全库链接、标题、meta、footer、课号、脚本名同步重排。
