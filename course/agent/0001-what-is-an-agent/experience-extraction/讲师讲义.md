# Agent 第 1 课 · 讲师讲义（培训三件套 · 配套课件说明）

> 配套课件：`0001-what-is-an-agent-课件-培训三件套.pptx`（23 页，阅读型）
> 课题：Agent 是什么：循环、工具、记忆　·　课时：约 60–75 分钟
> 目标学员：业务人员，不懂编程，零基础，用过 agent（仅处理文件/写报告/写 PPT）

## 一、教学策略（一张表）

- **教学目标**：学完能（1）说清用 AI 对话与用 Agent 差在哪，中间隔着 Workflow 一档；（2）分清模型/壳/Agent 三个词；（3）看懂循环怎么转、何时停；（4）说清工具从哪来、谁在动手；（5）说清记忆为什么没有标准做法。
- **教学重点**：三词区分（壳 vs Agent）、循环的转与停、判据"谁安排下一步"。
- **教学难点**：壳 vs Agent 最易混；循环出口与护栏。
- **教学方法**：案例引导（订机票钩子）+ 前后对比（网页版 vs Agent）+ 图示（循环图/三件套骨架）+ 互动提问（P10/P14/P18/P22）+ 当堂测（P22）。理论:案例:练习 ≈ 4:4:2。
- **时间分配**：开篇钩子 6 分钟 → 为什么（后台/壳，P4-6）12 分钟 → 循环（P7-11）18 分钟 → 三档怎么选（P12-14）12 分钟 → 三件套（P15-20）18 分钟 → 小结+当堂测（P21-23）9 分钟。

## 二、讲授主线

主线一句话：界面上都是同一个对话框，差别在背后那层"拿到回复还会接着干"的软件——它会自己转循环。

贯穿形象：**壳＝餐厅里的服务员**。P4 立起来（递单取件），P5/P6（端菜 vs 跑堂）、P10（发动机 vs 整车）、P18（真动手的是谁）反复用回。

## 三、逐模块怎么讲

1. **Why（P3-6）**：先抛"同一句话两个结局"钩子；点破后台只有"请求→回复"，差别在拿到回复之后——网页版只显示，壳会接着干。讲透请求/回复结构（字段名进备注）。
2. **What·核心（P7-11）**：循环＝推理→行动→观察→再推理；出口＝不再要工具给一段话；护栏＝最大步数；停了≠做对（关键动作先问用户）；三词各归各；顺带点一句上下文。
3. **How·怎么选（P12-14）**：三档（单次/Workflow/Agent）；判据＝谁安排下一步；别急着上 Agent。P14 场景小测过渡。
4. **三件套（P15-20）**：规划＝写出来的文字；工具＝一张说明卡（名字/干什么/参数），模型只说要调、壳执行；记忆分短时/长时，无标准做法，用失忆员工锚点。

## 四、必考/易忘点（当堂测覆盖）

- 下载装的是壳（harness），不是 Agent——Agent 是行为。
- "谁安排下一步"决定 Workflow vs Agent。
- 网页版与壳后台共同点＝都是"打包请求→取回复"。
- 真动手执行工具的是壳，不是模型。
